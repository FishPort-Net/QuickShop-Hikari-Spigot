This release fixes a Spigot 1.20.1 compatibility problem in the previous release.

## Changes

- Fixes `IncompatibleClassChangeError: Found class org.bukkit.inventory.InventoryView, but
  interface was expected` when QuickShop shuts down on Ketting/Spigot 1.20.1.
- Keeps QuickShop's core compiled against the Spigot 1.20.1 API even when the release is built with
  Java 21. Modern 1.20.5 and 1.21 platform adapters remain included.
- Disables checks for unsupported upstream QuickShop updates by default.
- Disables upstream Rollbar error reporting by default.

Servers upgrading from an older configuration should set `updater: false` and
`auto-report-errors: false` manually if those options are currently enabled.
