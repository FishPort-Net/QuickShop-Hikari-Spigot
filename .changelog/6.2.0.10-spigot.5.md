# QuickShop-Hikari-Spigot 6.2.0.10-spigot.5

This release keeps the dependency isolation introduced in `spigot.4` while moving the private
runtime out of the user-facing plugin JAR.

## Changes

- Reduces the plugin JAR to about 2.4 MiB. The pre-relocated runtime is downloaded once from this
  release and cached under `plugins/QuickShop-Hikari/libs`.
- Keeps Gson, Guava, Adventure, SLF4J, HTTP libraries, HikariCP, MySQL Connector/J, H2, and other
  private dependencies in the `com.ghostchu.quickshop.shade` namespace to prevent cross-plugin
  dependency conflicts.
- Verifies each downloaded runtime with SHA-256 and publishes checksums for both artifacts.
- Removes duplicate HTTP classes embedded in CrowdinOTA and unused MySQL X Protocol protobuf
  support, and replaces Commons Compress usages with Java standard ZIP/GZIP support.
- Keeps MySQL, H2, and CsvJdbc service providers merged and uses explicit relocated JDBC driver
  classes, preserving the `No suitable driver` fix.

## Compatibility

- Java 17: Ketting/Spigot 1.20.1 and the retained Spigot 1.20 R1-R3 adapters.
- Java 21: retained Spigot 1.20 R4 and Minecraft 1.21 through 1.21.5 adapters.
- Paper and Folia are not release targets.

The server needs outbound access to GitHub only on the first start after an update. The runtime
JAR can also be placed in the generated `plugins/QuickShop-Hikari/libs` cache for offline servers.
