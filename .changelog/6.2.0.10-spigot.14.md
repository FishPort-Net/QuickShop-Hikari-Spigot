This maintenance release fixes incomplete item tooltips in shop information previews on Spigot.

## Changes

- Sends only the ItemStack root tag in `show_item` hover events instead of nesting the complete
  serialized item storage structure inside the hover tag.
- Preserves custom item NBT used by modded clients to generate dynamic tooltip details such as
  brewing quality and effects.
- Keeps the fix generic without adding item- or mod-specific compatibility logic.
- Retains Java 17 support for Ketting/Spigot 1.20.1.
