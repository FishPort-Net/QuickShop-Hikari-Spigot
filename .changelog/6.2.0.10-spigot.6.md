This maintenance release prevents Carry On from moving QuickShop containers or signs while
leaving their shop records behind.

## Changes

- Blocks Carry On pickup gestures for shop containers, either half of a double chest, and attached
  shop signs for every player, including shop owners and administrators.
- Uses Carry On's synchronized key state when available, preserving custom carry-key bindings, with
  an empty-hands-and-sneaking fallback for incompatible Carry On versions.
- Adds an early block-break safeguard for Ketting's Forge-to-Bukkit event bridge so normal shop
  deletion listeners cannot remove the database record during a Carry On pickup attempt.
- Keeps the integration reflection-only and inactive when Carry On is absent, preserving pure
  Spigot and Java 17 compatibility without bundling Forge or Carry On classes.
- Fixes portable checksum generation in the GitHub Release workflow.

The external, pre-relocated private runtime introduced in `spigot.5` is unchanged and remains
downloaded once into `plugins/QuickShop-Hikari/libs` with SHA-256 verification.
