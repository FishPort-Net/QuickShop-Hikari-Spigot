This maintenance release adds per-virtual-account tax exemptions and fixes quota enforcement in the separately maintained Limited addon source.

## Changes

- Adds `shop.virtual-accounts.<account>.tax-free` to exempt every shop owned by a configured virtual account from transaction tax, independently of unlimited-shop status.
- Allows an explicit per-account `tax-free: false` value to override the legacy global unlimited-shop exemption.
- Retains `tax-free-for-unlimited-shop` as a compatibility fallback for existing configurations while removing it from new defaults.
- Fixes the Limited addon listener failing before it could cancel over-limit purchases when QuickShop's Adventure dependencies are privately relocated.
- Prevents `all` purchases from bypassing Limited quotas or producing negative remaining-limit values.
- Retains Java 17 support for Ketting/Spigot 1.20.1.
