This release adds core compatibility hooks for modded shop containers and configurable display
names for virtual shop owners.

## Changes

- Allows compatibility providers to resolve block-backed inventories without changing the normal
  Bukkit inventory path.
- Preserves inventory provider links when creating and reloading shops.
- Adds `shop.virtual-owner-display-names` for changing how virtual owner names appear on signs
  without changing the underlying economy account.
- Refreshes signs for loaded virtual-owner shops after `/quickshop reload`.

The display-name mapping is empty by default. For example, a server owner may add:

```yaml
shop:
  virtual-owner-display-names:
    bank-issue: '<gold>Issue Bank'
```

The shop owner remains `[bank-issue]` for economy transactions.
