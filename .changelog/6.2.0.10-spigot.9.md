This release fixes QuickShop failing to start because the EasySQL API was missing from the private
runtime dependency set.

## Changes

- Fixes `NoClassDefFoundError: cc/carm/lib/easysql/api/SQLManager` during plugin startup.
- Downloads, verifies, relocates and caches the EasySQL API as an isolated QuickShop dependency.
- Verifies the relocated EasySQL API before QuickShop continues initialization.
