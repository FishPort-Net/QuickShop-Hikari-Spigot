This maintenance release fixes virtual shop display items disappearing immediately after they are
spawned, particularly on hybrid or modded 1.20 servers.

## Changes

- Sends the destroy, spawn, item metadata, and optional velocity packets as one atomic client bundle
  for both PacketEvents and ProtocolLib. This prevents the client from ticking and discarding an
  empty item entity before its item metadata arrives.
- Indexes virtual displays by entity ID within each chunk and registers them only when first spawned,
  eliminating duplicate lifecycle entries and repeated refresh packets.
- Removes the redundant destroy packet previously sent before every chunk-triggered display refresh.
- Retains PacketEvents chunk-listener registrations so they can be correctly unregistered during
  plugin shutdown or reload.
- Preserves Java 17 support for Ketting/Spigot 1.20.1 and the Java 21 modern Spigot platform build.
