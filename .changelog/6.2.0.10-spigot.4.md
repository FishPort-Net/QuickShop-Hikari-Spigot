# QuickShop-Hikari-Spigot 6.2.0.10-spigot.4

This independently maintained AGPLv3 fork keeps QuickShop-Hikari 6.2.0.10 compatible with
Spigot, with Ketting/Spigot 1.20.1 and Java 17 as its primary target.

## Highlights

- Bundles and relocates private runtime dependencies and JDBC drivers to prevent conflicts with
  other plugins. H2, MySQL Connector/J, and CsvJdbc service descriptors are merged into the JAR.
- Adds the Spigot-compatible market browser and query architecture, shop tags, favorites,
  watching, asynchronous in-memory inventory counts, and display-entity rendering.
- Adds world whitelists, wildcard item blacklist expressions, configurable sign layouts,
  `/qs database save`, `/qs find` rate limiting, and a shop-limit calculation event.
- Exposes Crowdin OTA as configuration and disables it by default for administrator-maintained
  translation overrides.
- Restores left-click quick shop creation for ordinary containers after the interaction refactor.

## Fixes

- Separates buy and sell shops in price suggestions and enforces the configured maximum decimal
  places on every retained price update path.
- Avoids recursive deadlocks while sending virtual-display packets through ProtocolLib and
  PacketEvents, including the Minecraft 1.20 implementations.
- Fixes early configuration loading, command description remapping, supertool/GUI conflicts,
  optional-class lookups in paste reports, and display refresh when a shop changes type.
- Avoids generating debug log text when development mode is disabled.

## Compatibility

- Java 17: Ketting/Spigot 1.20.1 and the retained Spigot 1.20 R1-R3 adapters.
- Java 21: retained Spigot 1.20 R4 and Minecraft 1.21 through 1.21.5 adapters.
- Paper and Folia are not release targets.
- ProtocolLib 5.1.0 is compatible with the primary Minecraft 1.20.1 path; ProtocolLib 5.3.x is
  recommended when using later retained Minecraft versions.

The release asset is one self-contained Spigot JAR. Modern Java 21 platform classes are loaded
only when their matching server revision is detected, so Java 17 servers do not resolve them.
