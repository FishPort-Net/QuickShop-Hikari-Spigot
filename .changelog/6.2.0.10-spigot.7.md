This release improves QuickShop's dependency loading to prevent its libraries from conflicting
with other plugins. It also reduces repeated downloads when QuickShop is updated.

## Changes

- Isolates QuickShop's database, HTTP, logging, Adventure, Gson, and Guava libraries so they do not
  replace or interfere with copies used by other plugins.
- Downloads and prepares required libraries on the first startup, then reuses unchanged cached
  files after future QuickShop updates.
- Checks downloaded and prepared libraries for corruption and automatically downloads or rebuilds
  invalid cache files.
- Removes duplicate libraries embedded in several upstream components, avoiding startup behavior
  that depended on plugin class-loading order.
- Keeps MySQL, H2, and CSV database drivers available without exposing them to other plugins.

Java 17 remains supported for Ketting/Spigot 1.20.1. Modern Spigot 1.20.5 and 1.21 support remains
available when the server uses Java 21.
