This maintenance release improves PacketEvents compatibility with modded and hybrid servers.

## Changes

- Stops QuickShop's PacketEvents chunk listener from decoding complete chunk payloads when it only
  needs the chunk coordinates.
- Reads the chunk X/Z header from a duplicate packet buffer without advancing the original reader
  index.
- Avoids decoding modded biome, block, particle, and other registry-backed palette data in
  QuickShop's listener, preventing related chunk palette buffer overreads.
- Applies the fix to the PacketEvents 1.20, 1.21, and 1.21.6 implementations.
- Preserves Java 17 support for Ketting/Spigot 1.20.1 and the Java 21 modern Spigot platform build.
